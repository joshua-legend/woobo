# 인터랙션 컨셉 메뉴 — 우보 랜딩

> **살아있는 문서.** 섹션별 인터랙션 후보를 모아두고 → 검수에서 한 안을 **채택**으로 확정한다.
> 모션·카피·이미지는 `CLAUDE.md` 가드레일 준수. 이미지 슬롯은 `image-manifest.md` 참조.
> 상태: `후보 / 채택 / 구현됨 / 보류`

## 전역 결정
- **변주 비교 방식 = B · 히어로 토글** (1페이지, 히어로 컴포넌트만 교체). 02~08은 1벌 공유(중복 0).
  - 선택자: `/manifesto?hero=slot|kinetic|aperture` 쿼리파라미터 **또는** 우하단 dev 스위처. 검수용 — 픽 확정 시 한 안 고정 + 스위처 제거.
- 모션 토큰: `--ease`(소프트클로즈·기본) / `--ease-tip`(톡-팝) / `--ease-slam`(문제 섹션 1회 한정, 매니페스토엔 미사용).
- 스크럽 = 공용 `useScrub`(rAF+lerp). reveal = `useReveal`(`.reveal-up`/`.reveal-mask`).

### `hero-slot` (네 아이디어)
- **동작:** H1 프레임 `우리는 ___을 믿습니다` 고정, 가운데 단어만 라인마스크 슬롯 교체. 들어오는 단어 `--ease-tip` 톡-팝, 나가는 단어·배경 크로스페이드 `--ease`. above-fold라 **자동재생 타이머**(단어당 ~1.6–2.0s, 1.5바퀴 후 '움직임' 정지) 권장. 대안: 첫 스크롤 `useScrub`.
- **카피:** 교체 단어 `움직임 → 정밀 → 정품 → 디테일`(조사 `을/를` 자동), '움직임'에서 정지. 가드레일 안전.
- **이미지:** `hero-bg-motion / -precision / -authentic / -detail` (image-manifest 참조).
- **리스크:** above-fold 자동모션 산만 위험 / N이미지 LCP / 레이아웃 점프 / 합성 제품 ↔ 정품 메시지 충돌.

### `hero-kinetic`
- **동작:** H1 3줄 `.reveal-mask` 순차 어셈블 → '움직임' `--ease-tip` 1회 팝 → 6s 주기 미세 드리프트(±4–6px, `--ease`). 배경 차콜+헤어라인 스크롤 큐. **신규 JS 0.**
- **카피:** 현행 유지(`우리는 / [움직임]을 / 믿습니다.`).
- **이미지:** 없음(옵션 `hero-tex-grain`).
- **리스크:** 거의 없음 — 드리프트 진폭/주기 절제 필요.

### `hero-aperture`
- **동작:** 진입 `useReveal` 어셈블 → 첫 스크롤 `useScrub`로 '움직임' 텍스트-클립(배경 노출) 스케일/패럴랙스 0→1 보간, `--ease` 감속 → 02로 핸드오프.
- **카피:** 현행 유지(녹아웃은 '움직임' 단어 집중). 컷 위 차콜 80% 오버레이로 가독성.
- **이미지:** `hero-bg-aperture-a/b/c` 중 1.
- **리스크:** `background-clip:text` 대형 한글·사파리/모바일 호환 / 가독성(오버레이 의존) / 렌더 비용.
