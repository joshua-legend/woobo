## 1. 개요 & 목표
현재 섹션5는 세로 레이아웃(유럽 제조 → sole agent 6 카드 팝 → 고객)이다. 이를 **하나의 핀(pin) 섹션 안에서 세로 스크롤이 가로 이동으로 변환되는 횡스크롤 시네마틱 3막**으로 전면 교체한다. 콘텐츠 골격(원산지 → sole agent 6 → 고객)은 유지하되 인터랙션·프레임·이미지를 새로 만든다.

**성공 기준**: 데스크탑/모바일 모두에서 세로로 스크롤하면 섹션이 핀 고정된 채 3막이 가로로 흐르고 — ACT1 카드가 던져져 쌓이고, ACT2 6항목이 한 개씩 풀블리드로 교체되며 레일이 누적되고, ACT3 마무리 문구가 등장한다. 끊김 없이(rAF/스크럽) 진행되고, reduced-motion에서 정적 폴백된다.

## 2. 스크롤 메커니즘
- 섹션을 **핀 고정**(CSS sticky 트랙 + GSAP 진행도). 기존 `hooks/useScrub.ts`(ScrollTrigger 진행도 0→1) 재사용. `components/layout/SmoothScrollProvider.tsx`(데스크탑 Lenis / 모바일 `normalizeScroll(true)`) 그대로.
- 전체 진행도 `p`(0→1)를 **가로 트랙 translateX**로 변환. 트랙 = 횡으로 배열된 패널들: `[ACT1] [SA1][SA2][SA3][SA4][SA5][SA6] [ACT3]` (총 8 패널).
- **피스와이즈 매핑**(정확한 구간 비율·이징은 구현 플랜에서 튜닝):
  - ACT1 구간: 트랙을 ACT1 패널에 **머무르게(dwell)** 하면서 로컬 진행으로 카드 던지기 구동.
  - ACT2 구간: 6개 sole-agent 패널을 **한 개씩 가로로 통과**(스크롤 1스텝 ≈ 1패널). 노드 레일은 고정 오버레이로 현재 인덱스 반영·누적.
  - ACT3 구간: 마지막 패널에서 마무리 문구 reveal.
- 섹션 높이: 가로 이동량 + 막별 체류감 고려해 길게(초기값 ~480svh, 실측 튜닝).
- 모바일도 동일하게 가로 유지(요청). normalizeScroll 구간이라 **모멘텀/스텝 감은 실기기 튜닝 필요**.

## 3. ACT1 — 오리진 카드 던지기
- 배경: **검은색(차콜 `#16140f`)**, 시작은 빈 화면 + 미니 라벨("유럽 제조 · 원산지").
- 로컬 진행에 따라 카드가 **위에서 하나씩 던져져(throw)** 중앙에 **한 더미로 회전 적재**(트럼프 카드 더미, 카드별 회전각 상이).
- 카드 순서(던지는 순서 = 쌓이는 순서, Blum 맨 위·강조):
  1. AGOFORM — 독일 🇩🇪
  2. Peka — 스위스 🇨🇭
  3. **Blum — 오스트리아 🇦🇹 (간판, 맨 위, 강조)**
- 카드 구성: 회사명 + 원산지 + 생성형 이미지 슬롯(소형).
- 다 쌓이면 더미가 살짝 정렬되며 ACT2로 트랜지션(가로 이동 시작).

## 4. ACT2 — sole agent 6가지 (풀블리드 + 노드 레일)
- 각 항목 = **풀블리드 생성형 배경 이미지** + 하단 스크림 위 텍스트(번호 `0X / 06` · 제목 · 부제).
- **스크롤 1스텝 = 1항목**: 패널이 가로로 한 개씩 들어옴(이미지·텍스트 전환, ease = 소프트클로즈 `cubic-bezier(.16,1,.3,1)`).
- **노드 레일**(하단 고정 오버레이): 항목 넘어갈 때마다 노드 점등 + 주황(`#ff671f`) 게이지 누적, 현재 노드 확대.
- 6항목 콘텐츠(현재 `trust.tsx` FACETS 유지):
  1. Blum 한국 독점 에이전트 — 정품의 공식 통로 · sole agent
  2. 정품 보장 (유사품 차단) — A/S·부품 통로 확보
  3. 프리미엄 멀티브랜드 수입 — 유럽 하드웨어·소재 전문
  4. 가구 하드웨어 전문성 — 제작 현장을 아는 상담
  5. 전국 쇼룸 직접 체험 — 실물 확인 · 방문 예약제
  6. 자체 가구 생산 (김포 본점) — 하드웨어부터 완제품까지

## 5. ACT3 — 고객 마무리
- 마지막 패널, 시네마틱(어두운 톤 + 선택적 배경 이미지).
- 확정 카피(가드레일 준수 — 가격·"본사/코리아"·과장 없음):
  - 헤드라인: **"당신의 공간에 정품의 기준을."**
  - 부제: "Blum 한국 독점 에이전트, 우보브랜드샵."
  - CTA: **"전국 쇼룸 방문 예약 →"** (`href="#showroom"`)

## 7. 모바일 & reduced-motion
- 모바일: 가로 유지(핀 + 횡스크롤). normalizeScroll과 함께 동작, 스텝/모멘텀 실기기 튜닝.
- reduced-motion: 핀·가로이동 없이 3막을 **세로로 정적 나열** — ACT1 최종 쌓인 더미, ACT2 6항목(정적 카드/이미지), ACT3 마무리 문구. `useScrub`은 reduce에서 progress=1 통지하므로 최종형 렌더.
