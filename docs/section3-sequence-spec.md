# 섹션3 소프트클로즈 — 이미지 시퀀스 스펙 (디자인팀 전달용)

> 목표: CSS 박스 placeholder → **3D 렌더 프레임 시퀀스**로 교체해 모션을 포토리얼하게.
> 우리(웹)는 스크롤 진행도(0→1)를 **프레임 인덱스로 매핑**해서 재생. 소프트클로즈 감속은 **프레임에 baked** 되어 오는 게 베스트.

## 전달 규격
- **장면:** 서랍 1개가 **완전 열림(프레임 1) → 완전 닫힘(마지막 프레임)**. 측/사선 고정 카메라.
- **프레임 수:** **48장** (24~60 사이 가능. 많을수록 부드럽지만 무거움).
- **모션:** 실제 BLUMOTION **소프트클로즈 모션을 균등 시간 간격으로 샘플링** → 끝부분 감속이 자연히 담김. (균등 시간 = 끝에서 프레임 간 이동이 작아짐.)
- **카메라·조명·배경 고정** (프레임 간 흔들림 0). 배경은 **투명(알파)** 권장, 안 되면 페이퍼색 `#f4f1ec` 단색.
- **포맷:** `WebP`(또는 AVIF), **2x**. 장당 최적화 후 **~60–90KB**, 합계 **3–4MB 이내** 목표.
- **해상도:** 정사각 권장(스테이지가 1:1), 한 변 **1000–1200px @1x** (= 2000–2400 @2x는 무거우니 2x는 1000px급).
- **네이밍:** `close-001.webp` … `close-048.webp` (3자리 zero-pad, 1부터).
- **폴더:** `public/images/soft/` 에 투하.

## (선택) compare 변주용
- 두 세트: 일반 `close-plain-001…`, 소프트 `close-soft-001…`. 일반은 빨리 닫고 끝에 살짝 멈칫(과한 슬램 X).

## 우리 쪽 연결
- `?soft=sequence` 변주가 이 시퀀스를 `<canvas>`로 그림. 스크롤=프레임 스크럽, **드래그=프레임 스크럽 + 손 떼면 마지막 프레임까지 `--ease`로 재생**(던지고 사뿐히).
- 프레임 미존재 시 자동으로 `.ph` 폴백(자리·캡션만). 파일 넣으면 즉시 활성.
- 설정값(`SEQ`)이 위 규격과 1:1: dir `/images/soft/`, prefix `close-`, count 48, pad 3, ext `webp` → 규격 바뀌면 한 곳만 수정.
