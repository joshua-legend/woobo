# Woobo × Blum B2B 랜딩 — 디자인 프롬프트 정리본 (v2)

> **우보브랜드샵(Woobo) = Blum 한국 독점 에이전트(sole agent)·정품의 공식 통로·전국 쇼룸**의 B2B(제작사·시공자) + 일반 고객 대상 스크롤 랜딩 페이지. 운영 = **우보인터내셔날 주식회사**(프리미엄 하드웨어 수입 전문). **Blum 본사/코리아 아님** — 우리는 Blum 정품이 들어오는 한국의 공식 통로다. Blum 제품·기술·헤리티지는 *우리가 독점 취급하는 간판 브랜드*로 당당히 앞세운다.
> 핵심 컨셉: **"움직임(motion)이 곧 메시지"** — 모든 인터랙션의 시그니처 이징을 **소프트클로즈(부드러운 감속·정지)** 로 통일하고, 딱 한 곳(문제 제기 섹션)에서만 의도적으로 '쾅' 하고 이징을 깨뜨려 대비를 만든다.
> 카피는 한국어, 톤은 **제작자에게 말을 거는 1인칭** ("당신은 1mm까지 맞췄습니다").

> **포지셔닝 (대전제 = 우보브랜드샵 / Woobo)**: 이 페이지의 주인공은 **Blum 한국 독점 에이전트(sole agent)·전국 쇼룸을 운영하는 우보브랜드샵(Woobo)**이다. Blum 자랑은 "우리가 정품을 들여오는 한국의 공식 통로"로 당당히. 신뢰 신호 = **"Blum 한국 독점 에이전트 + 정품(유사품 차단) + 국내 A/S + 전국 쇼룸 직접 체험 + 자체 가구 생산 + 프리미엄 멀티브랜드 수입"**(병행수입·유사품·비공식 경로 대비)을 함께 심는다. CTA는 **쇼룸 방문 예약(전국 지점) + 견적·상담**으로 향한다. 출처: `brief/BRIEF.md` v6.

## 0. 글로벌 디자인 시스템

### 컬러 토큰
| 역할 | 값 | 비고 |
|---|---|---|
| 시그니처 오렌지 | `#ff671f` | Blum 브랜드 오렌지, 액센트 전용 |
| 오렌지 딥 | `#e4561a` | hover 상태 |
| 잉크(본문) | `#1c1a17` | 따뜻한 near-black |
| 잉크-2 / 잉크-3 | `#59544d` / `#8a847b` | 보조 / 캡션 |
| 페이퍼(배경) | `#f4f1ec` | 따뜻한 off-white 베이스 |
| 차콜(다크섹션) | `#16140f` / 카드 `#221f18` | 다크 섹션 배경 |
| 라인 | `#e2ddd4` (light) / `rgba(239,233,223,.14)` (dark) | 헤어라인 |

→ 라이트(페이퍼)와 다크(차콜) **두 배경만** 교차 사용. 오렌지는 액센트로만, 절대 면적으로 쓰지 않음.

### 타이포
- **헤드라인/마크**: Pretendard (700~800, letter-spacing −0.025~−0.05em)
- **본문**: IBM Plex Sans KR (300~700)
- **모노/라벨/eyebrow**: IBM Plex Mono (대문자, letter-spacing 0.18~0.32em) — 기술명·캡션·플레이스홀더 태그에 사용
- `word-break: keep-all` 로 한글 줄바꿈 보호, 헤드라인은 `text-wrap: balance`

### 이징 토큰 (★ 가장 중요)
- `--ease: cubic-bezier(0.16, 1, 0.3, 1)` → **소프트클로즈**. 거의 모든 transition·reveal·hover에 사용.
- `--ease-tip: cubic-bezier(0.34, 1.56, 0.64, 1)` → **TIP-ON 팝** (살짝 오버슈트). 톡 튀어오르는 요소에만.
- 문제 섹션의 '쾅'만 예외: `cubic-bezier(0.72, 0, 1, 1)` 0.13s (가속만, 멈춤 없음).

### 공통 UI / 모션
- **상단 고정 헤더**: 스크롤 40px 넘으면 `.small` 로 축소 + 반투명 블러 배경 + 하단 헤어라인.
- **스크롤 진행바**: 화면 최상단 2px 오렌지 바, 전체 스크롤 비율로 width 채움.
- **이미지/영상은 전부 placeholder**: 빗금(repeating-linear-gradient) + 모노 캡션("제품 마크로", "HERO VIDEO 16:9")으로 들어갈 콘텐츠를 명시. 실제 에셋은 추후 교체.
- **reveal 시스템 2종**:
  - `.up` → 아래에서 위로 fade+slide (24px).
  - `.mask` → 헤드라인을 `<br>` 단위로 줄 분할 후, 각 줄을 마스크 박스 안에서 112%→0 으로 밀어 올림(라인 마스크). 줄마다 70ms stagger.
  - 둘 다 IntersectionObserver 대신 스크롤 시 `getBoundingClientRect` 로 뷰포트 85% 진입 시 1회 발동.
- **접근성**: `prefers-reduced-motion: reduce` 시 모든 애니메이션 off, 요소는 최종 상태로 즉시 노출, 서랍은 닫힌 상태로 고정, 카운터는 최종값 표시.
- 메인 루프는 `requestAnimationFrame` + `lerp` 보간으로 스크럽값을 부드럽게 따라가게 함(즉시 점프 X).

## 종합 모션 원칙 (재현 시 반드시 지킬 것)
1. **하나의 이징으로 브랜드를 말한다** — 소프트클로즈(`0.16,1,0.3,1`)를 페이지 전체의 디폴트로. 모든 hover/reveal/transition이 같은 감속 곡선을 공유해 "조용히 멈추는" 촉감을 일관되게 전달.
2. **딱 한 번만 깨뜨린다** — 문제 섹션의 '쾅'만 가속 이징. 대비가 메시지를 만든다.
3. **스크롤 = 재생/제어 헤드** — 히어로 스크럽, 핀 스크롤리텔링, 트러스트 카운터 모두 스크롤 진행도에 1:1 바인딩(rAF + lerp).
4. **체험 > 설명** — Phase 3 드래그 핸드오프처럼, 말로 설명하는 대신 사용자가 직접 손으로 가치를 느끼게 한다.
5. **콘텐츠는 placeholder, 모션이 주인공** — 영상·제품샷은 빗금 + 모노 캡션으로 자리만 잡고, 실제 에셋 전 단계에서도 모션 의도가 100% 전달되게 한다.
6. **접근성 우선** — reduced-motion에서 전부 정적 최종 상태로 graceful degrade.
