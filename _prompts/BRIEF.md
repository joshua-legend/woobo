**보조 임무: "직접 보고 결정하도록 전국 쇼룸 방문 예약·거래/견적 문의로 잇는다."**

## 3. 핵심 통찰 (리서치 + 사이트 종합)

> **우리는 'Blum 한국 독점 에이전트(정품의 공식 통로)'다. Blum 제품을 당당히 앞세우고, 차별 신호는 "독점 정품(유사품 차단) + 멀티브랜드 큐레이션 + 전국 쇼룸 직접 체험 + 자체 가구 생산"이다.**

- **시장 측** [사실+추정]: 국내 Blum 접점은 병행수입·잡화몰이 많고 정품·전문성·실물 체험을 제공 못 함. → **"독점 에이전트 = 정품의 공식 통로 + 전국 쇼룸 + 전문 수입사"**가 즉시 차별화되는 빈 공간.
- **구매자 측** [추정/사실]: 제작사는 하자·총비용·납기, 일반 고객은 직접 확인·정품 안심. 공통 = **정품(독점 에이전트가 보증) + A/S + 실물 체험.** 병행수입·유사품 리스크 실재 → 우보의 "유사품 주의"가 이를 정면 공략.
- **제품 측** [사실]: Blum 권위·내구·모션은 강력 → 독점 공급사로서 당당히 활용. **자체 가구 생산(김포)**·대형가구사 공급(AGOFORM)은 "하드웨어를 가장 잘 다루는 곳" 전문성 증거.

## 4. 타겟·구매 여정

- **B2B 제작사**: 품질·정품·납기·총비용·평판. 경로 = KOFURN·도매몰 + 쇼룸 실물 확인.
- **일반 고객**: 직접 보고 만지는 안심, 전문가 상담, 시공/제작 연계(김포 자체 가구). 경로 = 검색·쇼룸 방문.
- **공통 = "직접 확인 → 상담 → 결정"** → **쇼룸 방문 예약**이 핵심 전환.

"한국 독점 에이전트라 **정품 보장(유사품 차단)** + A/S + **멀티브랜드 큐레이션** + **전국 쇼룸 직접 체험** + **자체 가구 생산(김포)** + 전문 상담."
- 정품/유사품 [사실, 자사 메시지] → 즉시 카피화. **"정품 Blum은 독점 에이전트 우보에서."**
- 전국 쇼룸 직접 체험 [사실] → 주요 CTA(방문 예약).
- 자체 가구 생산·대형가구사 공급 [사실] → 전문성 증거.
- A/S 범위·재고·납기·우보 연혁 → 8번 참조.

## 6. 앵글 (확정)

> **A 정체성(Blum 한국 독점 에이전트 Woobo) = 주축 / C 안심(정품·유사품 차단·A/S·직접 확인) = 보조.**

| 앵글 | 위상 | 근거 |
|---|---|---|
| **A. 정체성** (Blum 독점 에이전트·전문 수입사 Woobo) | **주축** | 국내 접점 대부분 잡화·병행수입 — "독점 정품 통로 + 전국 쇼룸"이 전면 공백. |
| **C. 안심** (정품·유사품 차단·A/S·실물 확인) | **보조** | 자사 "유사품 주의" 메시지 + 독점 에이전트 정품 보장. B2B·일반 공통. |
| **B. 평판** (취급 브랜드·거래처·실적) | 소재 | 멀티브랜드 포트폴리오·대형가구사 공급 = 신뢰. 동의분만 노출. |
| **D. 이익** (마진·납기) | 비주류 | 가격 전면화는 프리미엄·정품 포지션과 충돌 → 지양. |

**접근법**: **정체성(Woobo=Blum 독점 에이전트) → 제품(우리가 독점 공급하는 Blum, 당당히) → 안심(정품·유사품 차단·A/S·전국 쇼룸 직접 체험) → 사회적 증거(멀티브랜드·실적) → 쇼룸 방문 예약(CTA).**
