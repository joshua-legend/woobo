## 0. 글로벌 디자인 시스템 (3종 5·6·7 공통 — 내러티브만 다르게)

### 컬러 토큰
| 역할 | 값 |

| 시그니처 오렌지 | `#ff671f` (액센트 전용, 면적 금지) / hover `#e4561a` |

→ 라이트(페이퍼)·다크(차콜) 두 배경만 교차. 오렌지는 액센트로만.

### 타이포
- 헤드라인: Pretendard 700~800 (letter-spacing −0.025~−0.05em), `text-wrap: balance`
- 본문: IBM Plex Sans KR 300~700
- 라벨/eyebrow/모노: IBM Plex Mono 대문자 (letter-spacing 0.18~0.32em)
- `word-break: keep-all`

### 이징 토큰 (★)
- `--ease: cubic-bezier(0.16,1,0.3,1)` → **소프트클로즈**(거의 모든 transition·reveal·hover의 디폴트)
- `--ease-tip: cubic-bezier(0.34,1.56,0.64,1)` → **TIP-ON 팝**(살짝 오버슈트, 톡 튀는 요소만)
- 예외 1회: 문제 강조용 가속 `cubic-bezier(0.72,0,1,1)` 0.13s (이 버전에선 선택)

### 공통 UI/모션
- 상단 고정 헤더(스크롤 40px↑ 시 축소+블러), 최상단 2px 오렌지 **진행바**.
- 이미지/영상은 전부 **placeholder**(빗금 + 모노 캡션, 예 "제품 마크로", "HERO VIDEO 16:9", "쇼룸 전경").
- reveal 2종: `.up`(아래→위 fade+slide 24px), `.mask`(헤드라인 라인마스크, 줄당 70ms stagger).
- 메인 스크럽 루프 = `requestAnimationFrame` + `lerp` 보간(점프 금지).
- **접근성**: `prefers-reduced-motion`에서 전부 최종 정적 상태로 graceful degrade(카운터=최종값, 데모=완성 컷). 단 기본은 모션 ON.

### 제품 실용성 데모 3종 (5·6·7 공통 — "느낌"이 아니라 "현장 이득" + 쇼룸 체험 연결)
- **데모A · 소프트클로즈(BLUMOTION)** → *하자·클레임 재방문 ↓*. 세게 닫아도 사뿐히 멈춤.
- **데모B · 무공구 CLIP top + 3방향 조절** → *시공 시간·난이도 ↓*. 딸깍 장착 + 상하/좌우/깊이 미세조절.
- **데모C · TIP-ON 핸들리스(또는 LEGRABOX 하중·슬림)** → *디자인 자유도·완성도 ↑*. 손잡이 없이 톡 열림.
- ※ 3종 모두 Woobo가 **공식 취급하는 Blum 제품**. 데모 프레이밍: **"온라인에서 살짝 체험 → 전국 쇼룸에서 직접 만져보세요."**

## 종합 모션 원칙
1. 소프트클로즈(`--ease`)를 페이지 전체 디폴트로 — 일관된 "조용히 멈추는" 촉감.
2. 시그니처 데모는 **3개([3][4][5])**로 제한, 나머지는 가벼운 reveal. (절제)
3. 스크롤 = 제어 헤드: 데모는 스크롤 진행도에 1:1 바인딩(rAF+lerp).
4. **체험 > 설명**: 데모마다 "현장 이득"(하자↓/시공↓/디자인↑)을 카피로 1:1 명시 + **쇼룸 방문 유도** 마이크로카피.
5. 콘텐츠는 placeholder, 모션·메시지가 100% 전달되게.
6. reduced-motion graceful degrade. 기본은 ON.
